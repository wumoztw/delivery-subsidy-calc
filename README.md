# 外送專法與疊單收益精算系統 (Delivery Subsidy & Stacking Value Engine)

一套基於台灣勞動部外送專法規範、專為外送夥伴（Uber Eats）打造的**兩週週期差額補貼精算**與**疊單實質時薪產值推算系統**。支援截圖 OCR 自動辨識、CSV 匯入/匯出備份、LocalStorage 本地無痕保存與即時作戰模擬。

---

## 🚀 系統功能特色

1. **專法兩週週期差額精算**：
   - 自動累計雙週總服務工時（$T_{\text{total}}$，每單自接單至交付獨立累加）。
   - 根據專法法定保障費率（\$245/h 底線，支援自由自訂費率）精算最低應得保底（$\text{Total}_{\text{legal}}$）。
   - 自動計算兩週結算補發差額（$\Delta R = \max(0, \text{Total}_{\text{legal}} - R_{\text{base}})$）。
2. **跑單截圖頂級 AI 視覺解析 (NVIDIA Nemotron VL)**：
   - 採用 **NVIDIA Nemotron 12B VL 專屬多模態視覺模型**，支援 1800px 高清原圖閱讀。
   - 支援秒級精確換算（分 + 秒/60）、純點數疊單判定（點數 $\div 2$）與費用項拆解。
3. **「您的費用明細」單張獨立完整拆解**：
   - 清楚分列：基本行程費用、基本報酬加成、行程小計、顧客小費、活動獎勵與本趟實領總計。
4. **疊單工時放大與實質產值模型**：
   - 即時計算疊單工時放大倍數（$\text{Multiplier} = \frac{\sum T_i}{T_{\text{physical}}}$）。
   - 算出物理時薪產值（$Hourly\_Wage_{\text{real}} = \text{Multiplier} \times P_{\text{rate}}$）。
5. **雙向 CSV 匯入與備份匯出**：
   - 支援匯入歷史 CSV，並能一鍵匯出繁體中文 UTF-8（含 BOM）的標準試算表。
6. **數據無痕自動儲存 & 一鍵格式化報表**：
   - 採用瀏覽器 `localStorage` 即時儲存，關閉視窗不遺失數據，並可一鍵複製結算明細。

## 📐 核心結算三大基本公式

### 1. 外送服務期間總工時 ($T_{\text{total}}$)
$$T_{\text{total}} = \sum_{i=1}^{n} T_i = T_1 + T_2 + \dots + T_n$$
* **$T_i$ 定義**：第 $i$ 筆訂單自「接受派單」起至「送達交付」為止之完整服務時間。
* **疊單累加規則**：多筆訂單時間重疊時，每筆訂單之服務時間各自獨立累加計入法定工時。

### 2. 法定基本外送總額 ($\text{Total}_{\text{legal}}$，每兩週最低應得保障)
$$\text{Total}_{\text{legal}} = T_{\text{total}} \times P_{\text{rate}}$$
* **$P_{\text{rate}}$**：法定保障實質時薪費率。
  * 專法法定底線：\$245 元 / 小時（基本工資 \$196 $\times$ 1.25）。
  * 實務結算費率：約 \$293.90 ～ \$305.50 元 / 小時（納入每單最低保底與里程加成後）。

### 3. 基本報酬差額調整 ($\Delta R$，兩週實領補貼金額)
$$\Delta R = \max(0, \text{Total}_{\text{legal}} - R_{\text{base}})$$
* **$R_{\text{base}}$**：兩週週期內實領之基本報酬總額（淨行程費用 + 基本報酬加成）。
* **排除項目**：顧客小費、額外活動獎勵及非屬基本報酬之調整項目不計入 $R_{\text{base}}$。
* **補發規則**：若 $\Delta R > 0$，系統於兩週結算結束後自動全額撥付差額款項。

## ⚡ 跑單實質時薪產值模型

$$Hourly\_Wage_{\text{real}} = \left( \frac{\sum_{i=1}^{n} T_i}{T_{\text{physical}}} \right) \times P_{\text{rate}}$$

### 重疊倍數與實質時薪對照表（以 $P_{\text{rate}} = \$245$ 試算）

| 派單型態 | 60 分鐘內累加工時 | 工時放大倍數 | 法定保底實質時薪 |
| :--- | :--- | :--- | :--- |
| **單發單（1 單）** | 60 分鐘 | 1.0 倍 | **$245.00 元 / 小時** |
| **雙單疊單（2 疊）** | 100 ～ 110 分鐘 | 1.67 ～ 1.83 倍 | **$408.33 ～ $449.17 元 / 小時** |
| **三單疊單（3 疊）** | 140 ～ 160 分鐘 | 2.33 ～ 2.67 倍 | **$571.67 ～ $653.33 元 / 小時** |

## 🎯 時薪最大化作戰參數基準

* **2 疊單黃金標準**：總里程 $\le 2.5\text{ km}$，耗時 $\le 20\text{ 分鐘}$，等餐 $5 \sim 8\text{ 分鐘}$（雙倍計時最佳區）。
* **3 疊單黃金標準**：總里程 $\le 3.5\text{ km}$，耗時 $\le 30\text{ 分鐘}$，等餐 $8 \sim 12\text{ 分鐘}$。
* **拒接紅線**：2 疊單超過 $3.0\text{ km}$ 拒接；3 疊單超過 $4.0\text{ km}$ 拒接；送達點脫離核心熱區之訂單一律拒接。
