外送專法與疊單機制收益精算模型（Uber Eats）

本精算系統嚴格遵照勞動部專法草案與外送平台兩週週期結算規則設計。

1. 核心結算三大基本公式

1.1 外送服務期間總工時：T_total = ∑(T_i) = T_1 + T_2 + ... + T_n

• T_i 定義：第 i 筆訂單自「接受派單」起至「送達交付」為止之完整服務時間。
• 疊單累加規則：多筆訂單時間重疊時，每筆訂單之服務時間各自獨立累加計入法定工時。

1.2 法定基本外送總額：Total_legal = T_total × P_rate

• P_rate：法定保障實質時薪費率（專法法定底線：$245 元 / 小時；實務結算費率：約 $293.90 ～ $305.50 元 / 小時）。

1.3 基本報酬差額調整：ΔR = max(0, Total_legal - R_base)

• R_base：兩週週期內實領之基本報酬總額（淨行程費用 + 基本報酬加成）。
• 排除項目：顧客小費、額外活動獎勵及非屬基本報酬之調整項目不計入 R_base。

2. 跑單實質時薪產值模型與對照表
