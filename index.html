外送專法與疊單機制收益精算模型（Uber Eats）

本精算系統遵照外送專法草案規範與雙週結算規則設計。

1. 核心結算三大基本公式

1.1 外送總工時：T_total = ∑(T_i) = T_1 + T_2 + ... + T_n

• T_i 定義：自「接受派單」起至「送達交付」為止之完整服務時間。
• 疊單累加：多筆訂單時間重疊時，各自獨立累加計入法定工時。

1.2 法定基本總額：Total_legal = T_total × P_rate

• P_rate：法定保障時薪（專法底線：$245 元 / 小時；實務平均：約 $293.90 ～ $305.50 元 / 小時）。

1.3 基本報酬差額補貼：ΔR = max(0, Total_legal - R_base)

• R_base：雙週週期內實領之基本報酬（淨行程費 + 基本加成）。
• 排除項目：顧客小費與活動獎勵不計入 R_base。
